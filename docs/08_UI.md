# 08 — UI

WPF + **WPF UI (Wpf.Ui, Fluent)** 4.3.0. Shell = `ui:FluentWindow` with `ui:TitleBar`, a thin classic **Menu bar**
(File: Export…, Purge…, Exit · View: Theme, Language, Show hidden apps · Agent: Pause, Resume, Start, Stop, Health ·
Help: Docs, Privacy policy, About) and a left `ui:NavigationView` (`PaneDisplayMode="Left"`). Light/Dark/System via
`ApplicationThemeManager` + `SystemThemeWatcher`; Mica on Windows 11, solid fallback on 10. All XAML follows
`22_WPFUI_SYNTAX.md` — mandatory reading before writing views.

## Navigation

| Item | Page | Notes |
|---|---|---|
| Home | `HomePage` | today's top apps, alerts, heatmap, Agent health strip |
| Apps | `AppsPage` | running apps (grouped), live columns, search, picker button |
| Installed | `InstalledPage` | installed-but-not-running apps with footprint/last-seen/history |
| Alerts | `AlertsPage` | events with severity ≥ notice, acknowledge, filter |
| (footer) Settings | `SettingsPage` | |
| (not in rail) | `AppPage` | navigated to with `appId` + optional tab/event; back button visible here only |

Navigate only via `INavigationService.Navigate(typeof(Page), parameter)`; `AppPage` reads its parameter in
`INavigationAware.OnNavigatedTo`.

## Pages

### HomePage
- Four `ui:Card` "Top today" lists (CPU, Memory, Disk, Network) — 5 rows each, icon + name + bar + value; click → AppPage.
- `AlertsStrip`: last 5 unacknowledged events as `ui:InfoBar`s (severity-colored), "View all".
- `CalendarHeatmap` (ScottPlot `Heatmap`, 7 × 53) of total usage hours per day; hover → date + top 3 apps.
- `AgentHealthStrip`: mode (Full/Lite/Degraded), CPU %, RAM, events lost, sensor chips; click → Settings › Diagnostics.

### AppsPage
- `DataGrid` (virtualized) bound to `AppsTick` rows: icon, name, category chip, procs, CPU %, Memory, GPU %, Disk R/W,
  Net ↓/↑, sparkline (last 60 s, `SparklineControl` over the 1-h ring slice). Column chooser in a `ui:Flyout`.
- Toolbar: `ui:AutoSuggestBox` search (name, publisher, exe, pid), "Pick window" (crosshair), "Browse…" (file dialog →
  `ResolvePath`), group-by-category toggle, "Show system apps" toggle (default off: `sys:*` hidden except `sys:services` total).
- Row context menu: Open, Open install folder (UI-side `ShellExecute` on the canonical path; hidden for Tier 0/1),
  Policy…, Hide.

### InstalledPage
- From `GetInstalledApps` merged with `apps` table: name, publisher, version, source badge (MSIX/Steam/…), install root,
  last seen, footprint (latest `disk_snapshots`), 6-month network total. Not-running apps still open `AppPage` with
  History/Disk/Events tabs available and live tabs showing "not running".

### AppPage (the core)
Header `ui:Card`: 48-px icon, display name (editable via Policy), version, publisher, `SignatureBadge`
(Valid/Expired/Untrusted/Unsigned/CatalogSigned with tooltip showing signer chain), `CategoryChip` (click → change),
source + confidence (`?` badge < 0.60 → "Assign to app…"), install root (copy/open), first seen, today's usage time.
Tabs (`TabControl`, Fluent-restyled), each a separate `UserControl` + ViewModel, loaded lazily:

| Tab | Content | Data |
|---|---|---|
| Overview | 8 `MetricCard`s (CPU, Memory, GPU, Disk R/W, Net ↓/↑, Procs, Threads/Handles, Usage today) each with value, unit, 60-s sparkline, source tooltip (FR-20); "Last events" list; "Observed data folders" mini-list | `AppTick` + ring + SQLite |
| Processes | `DataGrid` of live instances: PID, started, parent chain (tooltip), command line (redact toggle, default per settings), user, session, IL, elevated, arch, runtime, CPU, Memory, I/O, Disk, Net, GPU, threads, handles, hard faults | `AppTick.procs` |

| Network | Live totals ↓/↑ with 60-s chart; `ConnectionsGrid` (proto, local, remote, host, state, dir, bytes, RTT, retrans, iface, loopback flag; filter by state/proto); `HostsTable` for a selected range (host, bytes ↓/↑, connections, first/last seen, proto mask icons) with expand → `HostRecords` (A/AAAA/CNAME chain, TTL, DoH); per-interface split; "Listening ports" section; policy banner ("Hostnames hidden for this app — change in Policy") | `ConnectionsTick`, SQLite, `ResolveHost` |

### AlertsPage
`events` with `severity ≥ 1`, newest first, grouped by day; acknowledge single/all; click → `AppPage` with the relevant
tab (NewHost → Network, Crash → Events, VersionChanged → Details, DataGrowth → Disk).

### SettingsPage (`ui:CardControl`/`ui:CardExpander` rows)
General (language, theme, start UI with Windows, show system apps, show command lines) · Agent (status, install/start/
stop, run at logon, budget readout, idle profile) · Privacy (retention slider 1–12 months, default host logging per
category, browser host logging opt-in with warning text, session scope, private window duration, purge all/app/range) ·
Data (DB path & size, export all, GeoIP DB download opt-in with license note) · Catalog (version, auto-update on/off,
update now, view rules) · Diagnostics (log level, open logs folder, sensor table, copy health report) · About.

## Components (`AppLedger.App/Controls`)

- `MetricCard` (value, unit, sparkline, trend arrow, source tooltip) — `Control` + template in `Styles/AppLedger.xaml`.
- `SparklineControl` — lightweight `DrawingVisual` polyline over a `double[]` (no ScottPlot per cell).
- `CategoryChip`, `SignatureBadge`, `SourceBadge`, `TierBadge` — `Border` + theme brushes (see 22 §Custom controls).
- `CapacityBar` — two-segment bar (app share vs used vs free) with accessible text.
- `TimeRangeSelector` — segmented `RadioButton`s styled as `ui:Button` group.
- `ChartHost` — wraps `WpfPlot`; applies `ChartTheme.Apply`; handles resize/throttle (max 10 redraws/s); exposes
  `Series`, `Markers`, `Range`; screen-reader summary text.
- `WindowPickerOverlay` — see §Window picker.

## Charts (ScottPlot 5)

- Time series: `Plot.Add.SignalXY(xs, ys)` for ring data (1 Hz) and `Scatter`/`SignalXY` for history; ≤ 5 series per
  plot; downsample to ≤ 4 000 points (min/max bucketing) before plotting.
- Bars: `Plot.Add.Bars` (horizontal) for top-N and directory breakdown.
- Heatmap: `Plot.Add.Heatmap` for the calendar.
- Markers: `Plot.Add.VerticalLine(x)` + `Annotation` for version changes/events; hatched `Rectangle` for `degraded` minutes.
- Axes: bytes axis uses a custom tick formatter (B/KB/MB/GB with culture); time axis `DateTimeAutomatic`.
- Theme: never set colors in pages; `ChartTheme.Apply(plot)` reads `Styles/ChartPalette.xaml` and subscribes to
  `ApplicationThemeManager.Changed` (22 §ScottPlot theme sync).

## Window picker (FR-3, FR-19)

Click "Pick window" → a transparent, topmost, full-virtual-screen `Window` with crosshair cursor; `MouseMove` highlights
the target via `WindowFromPoint` → `GetAncestor(GA_ROOT)`, drawing a `Border` over its rect; `MouseUp` → `ResolveWindow{hwnd}`
over the pipe (Agent does `GetWindowThreadProcessId`; if the owner is `ApplicationFrameHost.exe` it enumerates children
for class `Windows.UI.Core.CoreWindow` and uses that PID) → navigate to `AppPage`. `Esc` cancels. No hooks are installed.

## Onboarding (first run)

1. **Privacy Gate** page (`ui:Card` with sections): what is collected, where it is stored, default retention, browser
   policy, how to pause/purge, link to `PRIVACY_POLICY.md`. Primary "Continue", secondary "Read full policy".
2. **Agent setup**: explain the UAC prompt and "runs at logon" plainly; budget promise (< 1 % CPU idle, < 100 MB);
   buttons "Install Agent" / "Continue in Lite mode". Install → `runas` → wait for pipe → success state.
3. **Defaults**: retention slider, language, theme, start with Windows. Done → Home.

## Tray (H.NotifyIcon)

Left-click: show/hide window. Menu: Open, Pause collection (30 min / 2 h / until resumed), Private window…, Agent
status (read-only line), Exit. Balloon/toast on: Agent degraded, budget exceeded 10 min, alert with severity ≥ 1
(respecting Settings › Notifications). `WPF-UI.Tray` is not used (needs balloon + menu parity across Win 10/11).

## Notifications policy

- In-app transient: `ISnackbarService` (scan done, purge done, override applied).
- In-app persistent: `ui:InfoBar` (Lite mode, degraded sensors, policy banners).
- System toasts: only for alerts and Agent problems, via `Microsoft.Toolkit.Uwp.Notifications`; each toast deep-links
  to the relevant page (`appledger://app/<id>?tab=network` handled in-process via a single-instance pipe).

## States every page must implement

Loading (skeleton `ui:Card`s with `ui:ProgressRing`), Empty ("No data yet — the Agent has been collecting for 4 min"),
Not running (history tabs active, live tabs explain), Lite mode (banner + disabled columns with tooltips),
Degraded (hatched chart regions + banner), Error (InfoBar with "Copy details").

## Accessibility & i18n

Every control has `AutomationProperties.Name` from resx; charts expose a text summary (`ChartHost.SummaryText`);
all strings via `{x:Static res:Strings.Key}`; byte/percent/date formatting through `Formatters` (culture-aware);
keyboard: `Ctrl+K` search, `Ctrl+P` picker, `Ctrl+1..5` nav, `F5` refresh tab, `Esc` closes flyouts/picker.
